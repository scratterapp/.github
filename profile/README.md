<h3 align="center">Scratter</h3>

<p align="center">
  A native Apple Music client for Linux and Windows.<br>
  Unofficial and open source. Not affiliated with Apple.
</p>

---

**[scratter](https://github.com/scratterapp/scratter)** is a small C++23 player built as two
pieces. A background daemon, `scratterd`, handles playback, audio output and your desktop's
media keys. A lightweight window sits on top and can be closed whenever you like without
stopping the music.

It's early. On Linux the daemon already plays audio, takes remote commands and shows up in
the system media controls. Apple Music itself, the Windows side and the window are next.

**Want to help?** Read [CLAUDE.md](https://github.com/scratterapp/scratter/blob/main/CLAUDE.md)
for the rules and what to work on, then pick an open
[issue](https://github.com/scratterapp/scratter/issues).
